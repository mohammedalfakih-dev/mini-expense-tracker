# Mini Expense Tracker

## Stack

Use HTML for the expense form and list, CSS for styling, and plain JavaScript to add expenses and calculate the total.

## Commands

Once `index.html` exists, open it in a browser. Add expenses of `2.50` and `3.75` and check that both appear in the list and the total increases by `6.25`.

## Conventions

- Use semantic HTML and label each form input.
- Keep CSS in `styles.css` and JavaScript in `script.js`.
- Write comments in English.

## Do not

- Do not add JavaScript frameworks or build tools.
- Do not use inline styles.
- Do not commit files in `/notes`.
